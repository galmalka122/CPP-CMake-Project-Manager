## CMake Project Manager
A Python GUI tool designed to automate the repetitive setup tasks associated with C++ and CMake development.

### Core Features
* **Project Initialization**: Automatically generates the standard directory structure for new C++ projects.
* **Boilerplate Generation**: Creates `.cpp` and `.h` class files within existing project structures to maintain consistency.
* **Directory Management**: Integrated file browser to select and organize project locations via a graphical interface.

### Technical Stack
* **Language**: Python 3.x
* **Library**: Tkinter (GUI)
* **System**: File OS operations for automated directory and file creation.

### Usage
1. Run the application.
2. Select a root directory.
3. Choose to either "Create Project" for a new workspace or "Create Class" to add components to an existing one.
